# AndroidTransfer

A lightweight macOS desktop utility for seamless file transfers between Android devices and Mac using the Media Transfer Protocol (MTP) over USB. This project is currently in its initial setup stage (Pre-Alpha).

## Project Status & MVP Scope

Status: In Development / Pre-Alpha

Objective: Provide a fast, reliable, and native macOS MTP file management tool without relying on cloud services, third-party Android APKs, or active network connections.

MVP Scope:

- Automatic USB MTP device detection upon connection.
- Internal storage and SD Card directory tree parsing/rendering.
- Bidirectional file transfers (Mac <-> Android) for single and batch files.
